**Figma turns designs into shippable React code — moving onto the developers' turf**

- **Story type:** category-creation
- **Why a journalist cares:** A developer-tools / front-end engineering reporter at a technical trade outlet or dev-focused newsletter that covers the design-to-code workflow and the tools engineers actually adopt. The hook isn't "Figma added AI" — it's that a design tool now exports working React and HTML/CSS, which puts it adjacent to the front-end build pipeline rather than the handoff that precedes it. That reporter can test whether the generated code is something engineers would ship or throw away. Not for general consumer-tech press, marketing-tech desks, or AI-hype roundups.
- **Why now:** Make is launching now, so the design-to-code claim is fresh and testable today.
- **Decay:** 24hr — a launch is a one-day news event; the "does the code survive a code review" evaluation can run a bit longer if engineers weigh in.
- **What makes it distinct:** Ladder lens, zoomed up to the category — the story is the blurring line between design tools and the front-end build step, not the feature list. The founder/IPO and pricing angles below have different protagonists.
- **Proof it needs:** a sample of the exported React/HTML-CSS so an engineer can judge quality; a named team or developer willing to say whether they'd ship it; any benchmark Figma has on code accepted vs. rewritten. Without working code to inspect, this is a claim, not a story.
- **Facts it rests on:** Figma Make exports React and HTML/CSS from a Figma file; the AI assistant generates layouts from a text prompt.

- **What makes it distinct:** Perspective lens, the company-as-strategic-actor protagonist (post-deal Figma), and News peg — it leans on a real, supplied event (the collapsed Adobe acquisition) rather than the product itself. Different from the code-quality and pricing angles, which ignore the corporate context.
